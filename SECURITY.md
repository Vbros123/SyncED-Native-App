# Security policy

SyncED is currently a private, offline-first prototype. It does not include a production backend, authentication service, or server-side student-data store.

## Reporting a vulnerability

Do not open a public issue containing exploit details, credentials, personal data, or screenshots of private information. Report the issue privately to the repository owner with:

- the affected feature and platform
- clear reproduction steps
- the likely impact
- a suggested fix, when known

## Repository safety

Never commit API keys, signing certificates, provisioning profiles, Android keystores, student records, or real account data. Use fictional test data only. Native signing materials must remain outside Git.
